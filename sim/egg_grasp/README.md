# 三指鸡蛋抓取离线对照实验

本目录复现带壳生蛋、去壳熟蛋在固定抓姿下的载荷调节对照。仿真从三指预载建立后开始，到模型中的目标支撑面重新承重结束。全部力、滑移、损伤、时延和图像误差结果均来自合成数据。程序只计算数值，运行时不访问相机、CAN、灵巧手或 FPGA。

## 运行

在已有仓库的根目录打开终端。Ubuntu 的新环境可按以下步骤建立。Windows 将激活命令换为对应虚拟环境的 PowerShell 激活命令即可。

~~~bash
cd sim/egg_grasp
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest -v test_sim
python run.py --out reproduced
python plot_results.py --out reproduced
~~~

默认每个对象和运动组合生成 100 个虚拟样本，复用到各算法和误差场景。已提交的结果位于 `results/`。复现环境为 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、Matplotlib 3.10.8。其他兼容版本的数值优化和分位数末位可能略有差异。用 `--n` 可改变模拟样本数；改变批大小后随机数组也会改变。

## 实验对应关系

| 模块 | 实现和输出 |
|---|---|
| 七轴法兰轨迹 | `motion.py` 用厂商 URDF 的七个旋转关节原点、轴向和位置限位计算正运动学，在相同姿态下逐点求有界逆解。抬升 50 mm，横移 100 mm，保持后下降 50 mm。两种速度共享几何路径。分段五次曲线给出接触模型的名义加速度。输出 `kinematics.csv`。 |
| 接触与控制 | `contact.py` 实现位置增量式 PI、有接触耦合和响应滞后的弹簧、摩擦饱和、滑移累积，以及独立的压缩迟滞和个体损伤阈值。夹持成形后才开始比较。 |
| 侧视测宽 | `vision.py` 用针孔投影下的椭圆轮廓宽度模拟距离、转角、像素定位误差和失帧。比较像素比与经同平面尺度及姿态修正的宽度，输出 `vision.csv`。假定轮廓已经分割，未采集 D435i 图像。 |
| 时基 | `timing.py` 用带时钟漂移、接收抖动的脉冲模拟 AX7020 可记录的共同边沿。前 60 个配对拟合，后 120 个检验；另设通信事件晚于采样 6 ms 的反例。输出 `timing.csv`，无板卡实测或比特流。 |
| 统计 | `run.py` 执行分组、独立调参、配对比较和异常注入。按全部已启动回放统计，遇到不可行或观测过期立即结束该次正常转运。 |
| 验证 | `test_sim.py` 用独立 SLSQP 检查三维投影，覆盖含负系数、等号、空区间、共同中止、关节限位、时基语义及视宽误差。 |

## 物理假设与算法

每指分配的切向需求为负载比例乘以质量和重力加速度与轨迹加速度的向量和的模。支撑面在抬起和落下时逐渐转移载荷。各指模拟传感器只能看到摩擦饱和后的传递力和噪声。未传递的最大局部切向载荷用经验系数积分为滑移代理。法向接触位置固定，未求解物体六维力矩平衡、接触迁移、碰撞、壳体断裂力学和蛋白撕裂。逐指弹簧含 6% 共同位移耦合；执行器响应由独立内环更新。去壳蛋的隐藏压缩包含瞬时项、慢变项及力的二次项；控制器只使用带噪宽度、力与一步线性预测。模拟缩短到已经接触及回到支撑之间，不模拟初次接触、保护回放和张手后的损伤。

- A 使用按蛋类标定的固定三指向量，共用闭环 PI。每类在另 96 个虚拟样本（每种速度 48 个）上比较 6 个候选目标，以完成数、损伤数和较低标量依次打破并列。固定标量乘以三指比例 [1.16, 0.94, 0.90]。这属于实用基线，未穷举全部固定向量。
- B 使用同一 PI，计算每指目标下界 εF + max(预载下限, η(剪切读数+δτ)/μ下界) 及目标上界 F上限−εF，并与变化率和跟踪信赖区间相交。生蛋投影到盒约束；去壳蛋加上一步宽度约束。最小化与上一目标的加权平方距离和总载荷线性代价；半空间不满足时对拉格朗日乘子二分。已声明的摩擦和跟踪界是待检验的设计输入，仿真会产生越界样本。
- `shear` 是受剪切反馈研究启发的可执行参照：剪切利用率高于阈值则增力、低于滞回下沿则减力，亦用 6 个阈值在与 A 相同的独立调参样本上选择。它属于本项目实现。去壳蛋的 `B_noD` 仅撤去 B 的一步压缩约束，保留其余约束、底层和共同保护。
- 所有对象的质量均从 46–70 g 合成。损伤代理按虚拟个体的阈值判定，生蛋比较单指法向峰值，去壳蛋比较隐藏宽度损失。预设上限与个体阈值并不相同。本目录给出的力、周期、阈值和状态初值均为仿真假设，不能作为向实机发送的命令参数。

## 复核结果

| 对象与运动 | A 完成 / 100 | B 完成 / 100 | B 损伤代理 / 滑移终止 / 力区间中止 / 压缩中止 |
|---|---:|---:|---|
| 生蛋，平缓 | 95 | 82 | 10 / 1 / 7 / 0 |
| 生蛋，较快 | 96 | 68 | 11 / 0 / 21 / 0 |
| 去壳熟蛋，平缓 | 55 | 11 | 2 / 5 / 3 / 79 |
| 去壳熟蛋，较快 | 67 | 14 | 4 / 5 / 7 / 70 |

名义条件下 B 的合成完成率低于 A。去壳熟蛋增加压缩约束后，中止增加，损伤代理触发减少；中止后没有继续模拟，暴露时长也随之缩短。在低摩擦压力测试中，生蛋平缓工况 B/A 为 57/45，较快工况为 49/52。任何一组数字都不表示实物成功率。

每种蛋与运动有独立测试种子，种子从 51000 起，组内按 seed 和 id 配对。名义 A/B 共 800 次，名义剪切参照及去壳消融共 600 次，摩擦下降、观测过期、侧视噪声三类压力测试共 1600 次，总计 3000 次回放、400 个基础测试样本。压缩回归、余量确定、独立覆盖检查使用互不重叠的 11001、12001、13001 三组种子，每组 64 个虚拟个体，每个 44 步。校准文件列出所选基线参数和误差余量。名义模型默认宽度噪声标准差 0.0015；侧视压力测试以投影实验的绝对误差 P95/1.96 生成独立高斯扰动，检验误差尺度失配。

- `trials.csv` 每次一行。time_s 和力积分到首次终止或任务结束为止。outcome 是首要终止原因，damage 和 slip 保留到该时刻的独立标签。slip_limit 表示超过 2 mm 的模型代理阈值。
- `summary.csv` 给出每组分母、Wilson 95% 区间、失败分解、有效周期数、压缩预测和三个力学假设的覆盖率。覆盖按正常执行周期计，不应当作独立试验的成功率。
- `paired.csv` 给出 B 对同一虚拟个体其他方法的完成率差，以及按样本配对重抽 3000 次的百分位区间；适用范围为当前虚拟总体。真实鸡蛋采用不同蛋体随机分组。
- `trace_id0.csv` 固定展示各组第 0 个虚拟个体。额外的 `first_width_conflict.csv` 按编号取去壳平缓组第一个压缩不可行样本，用于定位失效机制。`width_min_minus_bound` 大于零且力盒非空即代表没有可行的目标。配图分别为 `nominal_outcomes.png` 和 `width_conflict.png`。

## 模型与文献出处

七轴几何数值取自 AgileX 官方模型。此处仅编码七个关节的运动学参数，分别检查法兰位姿、位置限位和离散速度。具体左右手型号、转接法兰、负载、接物托盘、手指运动、整机碰撞与动力学需按现场验证。[固定版本 URDF](https://github.com/agilexrobotics/agx_arm_urdf/blob/680fa925cd00db7e2628563d2edc5540963045de/nero/urdf/nero_description.urdf)

切向反馈、易损蛋抓取、形变检测分别参考以下原始工作。本文公开的是本项目的模型与控制器实现。[Ford 等](https://doi.org/10.1109/TRO.2025.3563046) · [Boonstra 等](https://doi.org/10.1109/ICRA57147.2024.10611517) · [Su 等](https://doi.org/10.1126/sciadv.adx4206) · [赵洲等](https://doi.org/10.16383/j.aas.c250453)
